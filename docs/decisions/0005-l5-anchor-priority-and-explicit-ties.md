# 0005. L5 앵커 기반 면허 충돌 예외와 명시적 동률 비교

- 날짜: 2026-10-22
- 상태: 로컬 구현·검증 완료, 팀 정책 검토 및 PR 대기
- 범위: ADR 0003의 마지막 직렬화 동률 비교를 대체하고, 동일 구간의 면허 충돌 예외를 추가한다. 기존 tier 우선 및 보호 구간 검사는 유지한다.

## 문제

직접 연결된 주문번호를 근거로 면허를 제외해도, 남은 송장번호가 고정 타입 순서로 이길 수 있었다. 전체 JSON 문자열 비교는 앵커 없는 후보를 선택하고, 비교 대상에서 제외한 confidence를 다시 비교하는 문제도 만들었다.

## 결정

1. 전달된 앵커/값의 원문 좌표 일치와 사이 문자열을 검사한다. 최대 6자이며 허용 조사와 구분자는 resolver에 명시한다. 줄바꿈이나 설명 문장은 직접 연결이 아니다.
2. 동일 segment_id/start/end의 면허와 직접 연결된 L4 RULE_ANCHORED 주문·송장·고객·계좌번호가 충돌할 때, 면허와 직접 연결되지 않은 동급 이하 번호 해석을 제외한다. 예외의 근거가 된 후보가 최종 후보군에 남는다. 다른 deterministic 후보는 유지한다.
3. JSON 전체 비교를 제거한다. 같은 타입/출처 그룹 안에서는 검증된 직접 연결 여부를 confidence보다 먼저 비교한다. 점수는 명확한 동일 source/type/tier 그룹에서 모든 값이 측정됐을 때만 비교한다.
4. 명시적 조건이 완전히 같고 비교 불가능한 confidence만 다르면 실패 처리한다. 순서에 따라 고르거나 점수를 합치지 않는다. 동일한 중복은 하나만 남기고, 이미 가려진 중복은 실패를 유발하지 않는다.
5. 실제로 선택되는 탐지만 대상으로 모호성을 검사하며, 보호 구간 누락/보호 수준 저하 검증은 기존과 동일하게 적용한다.

## 영향과 제한

모호한 중복은 이제 요청 실패가 될 수 있다. L5는 입력을 보존하고 L5_VALIDATION_FAILED를 반환하며 L6/L7은 진행하지 않는다. 원문 통과로 대체하지 않는다.

면허가 없는 모든 번호 간 충돌을 해결하는 일반적인 의미 분석은 아니다. 복수의 직접 연결 타입은 기존 고정 순서로 정리한다. 앵커를 L5에서 다시 찾거나 생산자 tier/confidence를 수정하지 않는다. None으로 confidence를 병합하는 안은 채택하지 않았다.

## 검증 및 후속 작업

[인수인계](../HANDOFF_팀원3_L5.md)에 수정 파일, 재현 명령, 최신 테스트 결과와 남은 L4 NER 설정 문제를 기록한다. [상세 상태](../status/11_L5_anchor_priority.md)에 L4 계약 확인 사항을 유지한다. 담당자 합의 및 전체 E2E 성공을 이 ADR로 대신 선언하지 않는다.

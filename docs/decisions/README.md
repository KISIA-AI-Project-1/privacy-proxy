# 설계 결정 기록 (ADR)

되돌리기 어렵거나 다른 레이어에 영향을 주는 결정을 여기 남긴다.
"왜 그렇게 했는지"를 나중에 다시 논쟁하지 않기 위한 기록이다.

## 언제 쓰나

- 레이어 간 계약(주고받는 자료 구조)을 바꿀 때
- 라이브러리·모델을 고를 때, 특히 대안을 검토하고 하나를 버렸을 때
- 보안·법령 해석이 걸린 결정 (예: 가역적 토큰화를 "가명처리"와 구분한 이유)

## 어떻게 쓰나

`0001-제목.md` 형태로 번호를 붙여 [0000-template.md](0000-template.md)를 복사해 쓴다.
한 번 머지된 ADR은 수정하지 않고, 뒤집을 때 새 ADR을 쓰고 이전 것을
`Superseded`로 표시한다.

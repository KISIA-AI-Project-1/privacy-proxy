# L5 실제 파이프라인 연결 준비

> 기준일: 2026-09-26 (KST)

## 현재 상태

- 실제 `assess_risk()`를 호출하는 `run_l5_risk_scoring()` 구현 완료
- 공통 `EntityType` 19종 중 L5 지원 18종만 평가
- `ETC`, 비표준 문자열, span 불일치는 `L5_VALIDATION_FAILED`
- 예외 메시지에 원문 개인정보를 포함하지 않음
- L5 실패 시 `status="failed"`가 되어 L6/L7 호출 조건 차단

## 병합 시 유지할 기준

- `EntityType` 정의는 `src/privacy_proxy/schemas.py` 한 곳만 유지
- `DetectedPII.entity_type`은 `EntityType | str`
- `tier` 기본값은 `MODEL`, `source` 기본값은 `unknown`
- L5에서는 enum 전체를 무조건 허용하지 않고 `ETC`를 제외한 18종만 평가
- L5 allowlist 검증을 overlap resolver보다 먼저 실행

# 평가 문장 작성 가이드

이커머스 상담원이 사내에서 LLM에 붙여 넣을 법한 요청을 써 주면 됨. 이 문서 말고 다른 평가 문서(README, 결과)나 탐지 코드는 **보지 말 것**.

## 쓰는 법

1. 아래 시나리오 중 하나를 골라, 실제 상담 현장에서 나올 법한 문장을 자유롭게 씀. 말투·길이·순서·띄어쓰기·오타 모두 자유. 실제 상담 기록에서 본 표현이면 더 좋음
2. 문장 안의 개인정보는 자리표시자로 둠. 값은 생성기가 가상값으로 채움
   - `{NAME}` 이름, `{PHONE}` 전화, `{EMAIL}` 이메일, `{AGE}` 나이(예: 34세), `{DOB}` 생년월일
   - `{RRN}` 주민등록번호, `{FRN}` 외국인등록번호, `{PASSPORT}` 여권번호, `{LICENSE}` 운전면허번호, `{BRN}` 사업자등록번호
   - `{ORDER_ID}` 주문번호, `{TRACKING}` 운송장번호, `{CUSTOMER_ID}` 회원/고객 번호, `{CUSTOMS_ID}` 개인통관고유부호
   - `{BANK}` 은행명, `{ACCOUNT}` 계좌번호, `{ADDRESS_ROAD}` 도로명 주소, `{ADDRESS_LOT}` 동/리+지번, `{ADDRESS_DETAIL}` 동·호수
   - `{DATE}` 날짜, `{AMOUNT}` 금액
3. 자리표시자로 못 쓰는 개인정보(건강 상태, 민감한 상품명, 구매 습관, 동네 이름, 영문 이름 등)는 직접 쓰고 `[[값|종류]]`로 감쌈
   - 종류: `SENSITIVE_HEALTH`(건강), `SENSITIVE_SEX_LIFE`(성생활), `PRODUCT_ITEM`(드러나면 곤란한 상품), `PURCHASE_PATTERN`(구매 습관·주기), `LOCATION`(지명), `PERSON_EN`(영문 이름), `AGE_GROUP`(연령대)
   - 애매하면 감싸 둘 것. "이 정보가 LLM 회사에 그대로 가면 곤란한가?"가 기준
   - **감싸는 범위는 그 정보를 드러내는 최소 단어(구)**. 조사·어미·서술어와, 빼도 같은 정보가 드러나는 말은 밖에 둠. 상품은 상품명 전체
     - `[[질염|SENSITIVE_HEALTH]]이 생겼다고` (O) / `[[질염이 생겼다고|SENSITIVE_HEALTH]]` (X)
     - `다음주 [[수술|SENSITIVE_HEALTH]] 잡혀서` (O) / `[[다음주 수술 잡혀서|SENSITIVE_HEALTH]]` (X)
     - 한 단어로 안 되면 구로: `[[남자친구랑 같이 쓰려고|SENSITIVE_SEX_LIFE]] 산거라`, `[[3년째 매달 정기배송|PURCHASE_PATTERN]] 받으시는`
4. LLM에게 시키는 일과 정답을 같이 적음

## 시나리오

환불·반품 판단 / 배송 지연 문의 / 주소·연락처 변경 / 해외직구 통관 / 환불 계좌 안내 / 본인·성인 인증 / 세금계산서 / 민감 상품(건강·성인용품) 문의 / 상담 내용 요약 / 고객 답장 초안 / 불만 분류

## 형식

```yaml
- id: 영문_짧은_이름          # 겹치지 않게
  group: hand_<작성자 이니셜>
  task: {type: 분류, reference: 불가}   # 분류|추출|QA|자유서술. 자유서술이면 reference: ''
  prompt: |
    {NAME} 고객님 주문 {ORDER_ID} 건인데요, 받은지 열흘 넘었고 박스 버렸대요.
    환불 기준은 수령 7일 이내 + 박스 있어야 함. 가능/불가로만 답해줘
  facts:                       # 답변에 꼭 남아야 하는 것
    - {fact: 불가, kind: invariant}            # 판단·숫자처럼 바뀌면 안 되는 것
    - {fact: '{ORDER_ID}', kind: equivariant}  # 답변에 그 값이 그대로 나와야 하는 것
```

- 분류·QA는 정답이 하나로 정해지게 지시문을 씀("가능/불가로만")
- facts는 1~3개. 자유서술 과제는 답장에 꼭 들어가야 할 값을 적음
- 1인 10~20건. 같은 시나리오도 문장 구조를 바꿔서 여러 개 써도 됨
